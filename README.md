# Student Performance Analysis Dashboard

## Project Overview
This project uses Power BI to explore student academic performance and identify patterns across different subjects and demographic groups.

## Objectives
- Analyze average Math, Reading, and Writing scores.
- Compare average scores by gender.
- Explore performance across parental education and ethnicity categories.
- Examine the relationship between test preparation status and average scores.
- Build an interactive dashboard using Power BI slicers and KPI cards.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Features
- KPI cards showing student count and average scores.
- Average Score by Subject.
- Student Distribution by Gender.
- Average Scores by Gender.
- Average Scores by Parental Education.
- Test Preparation vs Average Score.
- Interactive slicers for Gender, Ethnicity, Parental Education, and Test Preparation.
